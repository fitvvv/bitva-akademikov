# Битва Академиков

Карточная игра 4 класса Детской Академии Наук: колодостроение по мотивам Hero Realms, герои — ученики и сотрудники Академии.

Играть: https://fitvvv.github.io/bitva-akademikov/

- За одним устройством — с друзьями по очереди или против ботов.
- По сети — каждый со своего телефона: один создаёт комнату, остальные входят по коду.

Файл `index.html` собирается из папки `game` проекта командой `build.py` — здесь его не правят вручную.
